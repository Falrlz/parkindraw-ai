# ParkinDraw AI --- Branding

## Nama Produk

**ParkinDraw**

Nama ini menggabungkan:

-   **Parkin** --- merujuk pada Parkinson's Disease.
-   **Draw** --- merepresentasikan handwriting/drawing sebagai sumber
    data.
-   **AI** --- menunjukkan penggunaan artificial intelligence untuk
    analisis.

Untuk nama produk gunakan **ParkinDraw**. Untuk repository gunakan
`parkindraw-ai`.

## Tagline

**AI-assisted Parkinson's screening through drawing analysis.**

Alternatif singkat:

**Draw. Analyze. Screen.**

## Positioning

ParkinDraw AI adalah proyek end-to-end computer vision untuk **screening
berbantuan AI** terhadap Parkinson's Disease menggunakan pola gambar
tangan dari dataset NewHandPD.

Sistem menganalisis tiga jenis drawing:

-   Circle
-   Meander
-   Spiral

Output sistem merupakan **prediksi/screening berbasis model**, bukan
diagnosis medis definitif.

## Deskripsi GitHub

> An end-to-end AI system for Parkinson's disease screening using
> Circle, Meander, and Spiral drawings from the NewHandPD dataset.
